# Srimathi R — Technical Writing Portfolio

A responsive GitHub Pages portfolio for showcasing technical writing, AI documentation, developer experience and documentation UX work.

## Structure

- `index.html` — homepage
- `work.html` — portfolio/case-study index
- `about.html` — profile, approach and skills
- `contact.html` — contact links
- `case-studies/` — detailed portfolio pages
- `css/style.css` — visual system and responsive styling
- `js/main.js` — mobile navigation and work filters

## Publish on GitHub Pages

1. Create or open your GitHub Pages repository.
2. Copy these files into the repository root.
3. Commit and push.
4. In **Settings → Pages**, select **Deploy from a branch** and choose your main branch and `/ (root)`.
5. Open the generated GitHub Pages URL.

## Before publishing

Replace these placeholders in `contact.html`:

- `your.email@example.com`
- `https://www.linkedin.com/`
- `https://github.com/`

Also review every case study and replace generic/sanitized descriptions with portfolio-safe material from your own work. Do not publish confidential company information, internal screenshots, proprietary source code, customer information, or unpublished product details.

## Design

The site uses a restrained editorial/documentation aesthetic with Cormorant Garamond for display typography and DM Sans for interface/body text. Google Fonts are loaded remotely; if offline, the site falls back to system fonts.
